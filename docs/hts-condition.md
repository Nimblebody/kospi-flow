# HTS [0110] 조건검색 — 장중 스크리너용 조건

앱의 장중 스크리너는 여기서 만든 조건의 결과를 받아온다 (psearch-result).
수치는 출발값이다. 쓰면서 바꾼다.

## 만드는 법

eFriend Plus [0110] 은 코드를 붙여넣는 방식이 아니다. 항목 트리에서 지표를 골라
값을 넣고 '추가' 하면 A, B, C … 로 쌓이고, 아래 조건식 줄에서 `A and B and C`
처럼 엮는다. 메뉴 이름은 버전마다 다를 수 있으니 항목 검색창에 '체결강도'
'거래대금' 처럼 이름으로 찾는다.

## 조건 (출발값)

| 기호 | 항목 | 값 | 이유 |
|---|---|---|---|
| A | 거래대금 (당일 누적) | 50억 원 이상 | 체결강도 999.99 짜리 거래 없는 종목이 여기서 대부분 걸러진다 |
| B | 거래량 전일 대비 비율 | 150% 이상 | 절대 거래량은 주가 수준마다 뜻이 달라 비율로 본다 |
| C | 체결강도 | 120 이상 500 이하 | 위쪽을 막는 이유 — 매도 체결이 거의 없으면 999.99 로 찍힌다 |

조건식

    A and B and C

### 단위 주의
거래대금 입력 단위가 백만원이면 50억은 `5,000` 이다. 억원이면 `50`, 원이면
`5,000,000,000`. 입력칸 옆 단위를 꼭 본다.

### B 를 비율 항목으로 못 찾으면
'거래량' 절대값으로 대신한다. 출발값은 100만 주 이상.

## 제외 — 대상변경 설정은 API 에 안 먹는다

KIS 공식 예제에 이렇게 적혀 있다.

> [0110] 화면의 '대상변경' 설정사항은 HTS [0110] 사용자 조건검색 화면에만 적용됨

HTS 화면에서 ETF·스팩·관리종목을 '대상변경' 으로 뺐어도 API 결과에는 그대로
섞여 나온다. 빼고 싶으면 조건 안에 제외 항목으로 넣는다(항목 추가 시 '제외'
선택지가 있으면 그것을 쓴다). 없으면 앱에서 거른다.

실측(2026-09-17 14:42)으로 체결강도 상위를 거르지 않고 불렀더니 스팩·ETF·
거래량 수백 주짜리가 30개를 다 채웠다. 제외는 꼭 챙긴다.

## 저장 — 이걸 안 하면 API 에서 안 보인다

조건을 만든 뒤 [0110] 왼쪽 아래 **'사용자조건 서버저장'** 을 누른다.
저장 안 하고 API 를 부르면 '조회가 계속 됩니다' 오류가 난다(공식 예제 안내).

## 알아둘 제한 (공식 예제 기준)

- 조건 하나당 결과는 **최대 100종목**. 너무 느슨하면 잘린다. 장중에 80개를
  넘기면 조건을 조인다.
- 결과가 0건이면 오류 `MCA05918 종목코드 오류입니다` 로 온다. 앱은 이걸 '해당
  없음' 으로 본다.

## 앱 쪽 문턱과의 관계

앱에서 체결강도·거래대금·등락률·시총 문턱을 다시 조절할 수 있다(추가 호출 없음).
그래서 HTS 조건은 앱 문턱보다 **조금 느슨하게** 두고, 앱에서 조인다.
단 위의 100종목 제한 때문에 지나치게 느슨하면 안 된다.

| | HTS 조건 | 앱 기본 문턱 |
|---|---|---|
| 거래대금 | 50억 이상 | 100억 이상 |
| 체결강도 | 120~500 | 130 이상 |
